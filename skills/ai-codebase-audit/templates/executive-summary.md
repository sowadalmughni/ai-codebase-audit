## What Was Audited

This audit assessed [PROJECT NAME] against the six failure modes that cause AI-generated codebases to fail in production:

1. **Schema Connectivity** — Are all database tables wired to the application?
2. **Frontend Integration** — Do all pages call real API endpoints?
3. **Backend Wiring** — Are all backend services reachable by the application?
4. **Data Security (RLS)** — Is user data protected at the database layer?
5. **Infrastructure Efficiency (N+1)** — Will the app survive real production load?
6. **Secret Exposure** — Are credentials protected from public access?
